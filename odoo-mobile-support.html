Help & setup

Odoo Mobile support

Installation, connection and troubleshooting guidance for the Android client.

Install the APK

  1. Download the signed release APK from the website.
  2. Open the downloaded file on your Android device.
  3. If Android blocks the installer, allow installs from the browser or file manager you used.
  4. Complete installation and open Odoo Mobile.

Minimum supported Android version: Android 8.0 / API 26.

Connect to Odoo

On first launch, create a connection profile with your server URL, exact database name and one of the supported authentication methods.

  1. Enter a friendly connection name.
  2. Use an HTTPS Odoo base URL, for example https://company.example.com.
  3. Enter the exact Odoo database name.
  4. Choose API key or username/password authentication.
  5. Run the required connection test and save only after it succeeds.

Recommended Odoo permissions

Use a dedicated least-privilege Odoo account. Grant only the Contacts, Sales, Inventory, Purchasing and Accounting rights the user actually needs. The app discovers effective access at runtime and hides unsupported actions.

Quick checks

Cannot connect?
Confirm the server opens in a browser, HTTPS is valid, the database name is exact and the credentials are correct.

Missing a module?
The connected user may not have access, or the required Odoo model/field may not be installed.

Offline?
Cached customers open read-only offline. To Do changes, photos, signatures and task documents can queue for encrypted retry with recovery and conflict review. Sales, accounting, inventory, purchasing actions and private chats need connectivity.

Multi-company?
Check the selected company in Administration. Business requests include the saved company context.

Security note

Credentials are encrypted on the device. Never embed Odoo passwords or API keys in source code, screenshots, logs or public issue reports.
